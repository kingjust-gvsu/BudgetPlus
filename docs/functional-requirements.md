•	FR-1: The system shall let users sign in and out with a Google account.
•	FR-2: The system shall let the user enter and change their estimated monthly income.
•	FR-3: The system shall let the user set each expense's budget as a fixed amount, a percentage of income, or the remainder, and shall use a fixed estimate for bills.
•	FR-4: The system shall allow only one remainder category and set it to income minus all other budgets.
•	FR-5: The system shall warn the user when fixed and percentage budgets add up to more than their income.
•	FR-6: The system shall let the user add, edit and delete transactions with a date, description, amount and optional category.
•	FR-7: The system shall import transactions from a CSV file after the user maps its columns to date, description and amount.
•	FR-8: The system shall show each expense's amount spent against its limit, marked green when under and red when over.
•	FR-9: The system shall let the user give a bill a frequency (every N months) and a next due date.
•	FR-10: The system shall let the user switch between months on the dashboard.
