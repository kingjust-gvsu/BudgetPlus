NFR-1 (Security): The system shall use Firebase to handle sign-in, check the sign-in token on every API request, and allow users to read or change only their own data.
NFR-2 (Privacy): The system shall never connect to banks or store bank credentials or account numbers.
NFR-3 (Accuracy): The system shall store and calculate all money in whole cents, so totals are exact to the cent.
NFR-4 (Performance): The system shall load the dashboard in under 2 seconds for a user with 5,000 transactions.
NFR-5 (Usability): The system shall let a new user set up a basic budget (income, 3 bills, 3 expenses) in under 5 minutes.
